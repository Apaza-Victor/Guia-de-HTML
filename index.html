Introduccion a HTML5

HTML (HyperText Markup Language) es el lenguaje de marcado estándar para crear páginas web. Define la estructura y el contenido de una página web mediante el uso de elementos (etiquetas) que representan diferentes tipos de contenido.

Que es HTML5?

HTML5 es la quinta revision importante del lenguaje HTML. Es la versión mas reciente y estándar, que introduce nuevas funcionalidades, elementos semánticos y APIs que permiten crear aplicaciónes web mas potentes y accesibles.

Caracteristicas principales

  • Elementos semanticos: Etiquetas que describen su significado (<header>, <nav>, <article>, <footer>)
  • Multimedia integrada: Soporte nativo para audio (<audio>) y video (<video>)
  • Canvas y SVG: Para graficos y animaciones
  • APIs del navegador: Geolocalización, Almacenamiento local, Drag & Drop, Web Workers, etc.
  • Formularios mejorados: Nuevos tipos de input y validación
  • Soporte offline: Service Workers y Cache API
  • Mejoras en accesibilidad: ARIA roles y atributos
Por que aprender HTML?

HTML es la base de todo sitio web. Sin importar que framework o tecnologia uses, HTML siempre sera necesario para estructurar el contenido en la web.

Seccion 01

Estructura Basica de HTML

Toda página HTML sigue una estructura básica que incluye una declaración de tipo de documento, la raiz del documento, la seccion de encabezado y el cuerpo con el contenido visible.

HTML
<!DOCTYPE html> <!-- Declara que el documento es HTML5 -->
<html lang="es"> <!-- Raiz del documento, lang define el idioma -->
<head> <!-- Contiene metadatos, no se muestra en la página -->
  <meta charset="UTF-8"> <!-- Codificacion de caracteres (acentos, eñes) -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!-- Responsivo en movil -->
  <title>Mi primera página</title> <!-- Titulo que aparece en la pestana del navegador -->
</head>
<body> <!-- Todo el contenido visible va aqui -->
  <h1>Hola, mundo</h1> <!-- Titulo principal (solo uno por página) -->
  <p>Mi primera página web</p> <!-- Parrafo de texto -->
</body>
</html>

Seccion 02

HTML Semantico

HTML5 introdujo elementos semánticos que describen el significado del contenido que contienen, en lugar de solo definir su apariencia. Esto mejora la accesibilidad, el SEO y la mantenibilidad del codigo.

Etiquetas semánticas principales

<header>

Contenido introductorio o de navegación.

<nav>

Enlaces de navegación principales.

<main>

Contenido principal. Solo uno por página.

<article>

Contenido independiente y autocontenido.

<section>

Agrupa contenido tematico.

<aside>

Contenido complementario (sidebar).

<footer>

Pie de página.

<time>

Fecha o hora especifica.

<figure>/<figcaption>

Contenido ilustrativo con leyenda.

<details>/<summary>

Contenido colapsable.

Estructura semántica completa

HTML
<body> <!-- Contenedor principal del contenido visible -->
  <header> <!-- Encabezado global del sitio -->
    <nav> <!-- Barra de navegación principal -->
      <a href="/">Inicio</a>
      <a href="/blog">Blog</a>
      <a href="/contacto">Contacto</a>
    </nav>
  </header>
  <main> <!-- Contenido principal (solo uno por página) -->
    <article> <!-- Contenido independiente y autocontenido -->
      <header> <!-- Encabezado del articulo -->
        <h1>Titulo del articulo</h1>
        <time datetime="2024-01-15">15 de enero, 2024</time> <!-- datetime: formato ISO para buscadores -->
      </header>
      <section> <!-- Seccion tematica dentro del articulo -->
        <h2>Introduccion</h2>
        <p>Contenido del articulo...</p>
      </section>
      <figure> <!-- Contenido ilustrativo con leyenda -->
        <img src="diagrama.png" alt="Diagrama">
        <figcaption>Diagrama de arquitectura</figcaption> <!-- Leyenda de la imagen -->
      </figure>
      <footer><p>Autor: Juan Perez</p></footer> <!-- Pie del articulo -->
    </article>
    <aside> <!-- Contenido complementario (barra lateral) -->
      <h3>Articulos relacionados</h3>
      <ul><li><a href="#">Otro articulo</a></li></ul>
    </aside>
  </main>
  <footer><p>&copy; 2024 Mi Sitio</p></footer> <!-- Pie de página global -->
</body>
No abuses de las etiquetas semánticas

Cada etiqueta tiene un proposito especifico. Usa <section> para contenido tematico, no como sustituto de <div>.

Iframes, Embed y Object

Incorpora contenido externo en tus paginas

Las etiquetas <iframe>, <embed> y <object> permiten incrustar contenido de otras fuentes directamente en tu pagina web, como videos, mapas, PDFs o paginas externas.

HTML
<!-- Iframe basico: embebe otra pagina web -->
<iframe
  src="https://www.ejemplo.com"
  width="800"
  height="450"
  title="Descripcion del contenido embebido"
  loading="lazy"
  sandbox="allow-scripts allow-same-origin"
  referrerpolicy="no-referrer"
></iframe>

<!-- Iframe responsivo con contenedor -->
<div style="position:relative;padding-bottom:56.25%;height:0;overflow:hidden">
  <iframe
    src="https://www.youtube.com/embed/VIDEO_ID"
    style="position:absolute;top:0;left:0;width:100%;height:100%;border:0"
    allowfullscreen
    loading="lazy"
    title="Video de YouTube"
  ></iframe>
</div>

<!-- Embed: contenido embebido (PDF, plugin) -->
<embed
  src="documento.pdf"
  type="application/pdf"
  width="100%"
  height="600px"
>

<!-- Object: contenido alternativo con fallback -->
<object
  data="animacion.svg"
  type="image/svg+xml"
  width="400"
  height="300"
>
  <img src="fallback.jpg" alt="Descripcion" />
</object>

Formularios Avanzados

Validación nativa, FormData y Constraint Validation API

Más allá de los tipos de input básicos, HTML5 ofrece una API completa de validación nativa que elimina la necesidad de librerías externas para muchos casos comunes.

HTML + JS
<!-- Constraint Validation API -->
<form id="miFormulario">
  <input type="email" required minlength="5" pattern="[a-z]+@[a-z]+\.[a-z]{2,}">
  <input type="text" required maxlength="50">
  <button type="submit">Enviar</button>
</form>

<!-- JavaScript: Validacion personalizada -->
const form = document.querySelector('#miFormulario');
const email = form.querySelector('input[type="email"]');

// Validar al enviar
form.addEventListener('submit', (e) => {
  e.preventDefault();
  if (!form.checkValidity()) {
    // Muestra los mensajes de error nativos del navegador
    form.reportValidity();
    return;
  }
  // Crear FormData automaticamente desde el formulario
  const datos = new FormData(form);
  for (const [clave, valor] of datos) {
    console.log(`${clave}: ${valor}`);
  }
});

// Personalizar mensaje de error
email.addEventListener('input', () => {
  if (email.validity.typeMismatch) {
    email.setCustomValidity('Ingresa un email valido (ejemplo@dominio.com)');
  } else {
    email.setCustomValidity(''); // Limpiar error personalizado
  }
});

Seguridad HTML

Protege tu sitio con atributos y meta tags de seguridad

HTML5 ofrece varios atributos y configuraciones para proteger tu sitio web contra ataques comunes como XSS (Cross-Site Scripting), clickjacking y inyección de código malicioso.

HTML
<!-- Content Security Policy (CSP) via meta tag -->
<meta http-equiv="Content-Security-Policy"
  content="default-src 'self'; script-src 'self' https://cdn.ejemplo.com; style-src 'self' 'unsafe-inline'; img-src 'self' data: https:;">

<!-- Iframe sandbox: restringe funcionalidades -->
<iframe src="externo.html"
  sandbox="allow-forms allow-scripts"
></iframe>
<!-- Sin sandbox: todo permitido | allow-scripts: permite JS | allow-same-origin: mantiene origen -->

<!-- Links externos seguros -->
<a href="https://ejemplo.com"
  target="_blank"
  rel="noopener noreferrer">Enlace externo</a>
<!-- noopener: impide que la pagina abierta acceda a window.opener -->
<!-- noreferrer: no envia informacion del referer -->

<!-- Subresource Integrity (SRI) -->
<script
  src="https://cdn.ejemplo.com/libreria.js"
  integrity="sha384-oqVuAfXRKap7fdgcCY5uykM6+R9GqQ8K/uxy9rx7HNQlGYl1kPzQho1wx4JwY8wC"
  crossorigin="anonymous"></script>
<!-- Verifica que el archivo no fue modificado en el CDN -->

<!-- Meta tag: prevenir sniffing de tipos -->
<meta http-equiv="X-Content-Type-Options" content="nosniff">

<!-- Prevenir framing (clickjacking) -->
<meta http-equiv="X-Frame-Options" content="DENY">

Vulnerabilidades y Protecciones

AmenazaProteccion HTMLDescripcion
XSSCSP + escape de contenidoEvita inyeccion de scripts maliciosos
ClickjackingX-Frame-OptionsImpide que tu sitio sea embebido en iframes maliciosos
Tabnabbingrel="noopener"Impide que links en target=_blank manipulen la pagina original
Tampering CDNSRI (integrity)Verifica que archivos externos no fueron modificados
MIME sniffingX-Content-Type-OptionsImpide que el navegador interprete archivos como otro tipo
Data leakagerel="noreferrer"No envia informacion del sitio de origen
Siempre escapes el contenido del usuario

Nunca insertes texto del usuario directamente en HTML con innerHTML. Usa textContent o librerias de escape como DOMPurify para prevenir ataques XSS.

API de Geolocalización

JavaScript
if ('geolocation' in navigator) { // Verifica si el navegador soporta geolocalización
  navigator.geolocation.getCurrentPosition( // Solicita la posición actual del usuario
    (position) => { // Callback de exito con la posición
      const { latitude, longitude } = position.coords; // Extrae latitud y longitud
      console.log(`Lat: ${latitude}, Lng: ${longitude}`); // Muestra las coordenadas
    },
    (error) => { // Callback de error si falla la geolocalización
      console.error('Error:', error.message); // Muestra el mensaje de error
    },
    { enableHighAccuracy: true, timeout: 10000 } // Opciones: alta precision, timeout de 10s
  );
}

Service Workers y Cache API

Controla el trafico de red y habilita modo offline

Un Service Worker es un script que el navegador ejecuta en segundo plano, separado de la pagina web. Intercepta las peticiones de red y puede cachear, filtrar o modificar respuestas, habilitando experiencias offline.

JavaScript
// Registrar Service Worker (en tu pagina principal)
if ('serviceWorker' in navigator) {
  navigator.serviceWorker.register('/sw.js')
    .then(reg => console.log('SW registrado:', reg.scope))
    .catch(err => console.error('Error SW:', err));
}

// sw.js - Archivo del Service Worker
const CACHE_NAME = 'guia-html5-v1';
const urlsToCache = ['/', '/css/styles.css', '/js/app.js'];

// Instalar: cachea archivos estaticos
self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => cache.addAll(urlsToCache))
  );
});

// Activar: limpia caches antiguos
self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then((keys) =>
      Promise.all(keys.filter(k => k !== CACHE_NAME).map(k => caches.delete(k)))
    )
  );
});

// Fetch: estrategia cache-first o network-first
self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request).then((cached) => {
      return cached || fetch(event.request);
    })
  );
});

Web Fonts

Carga fuentes personalizadas de forma optimizada

Las fuentes web permiten usar tipografias personalizadas en tus paginas. HTML5 ofrece varias formas de cargarlas de forma optimizada para no afectar el rendimiento.

HTML
<!-- Metodo 1: Google Fonts con preload (recomendado) -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="preload" as="style"
  href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap">
<link rel="stylesheet"
  href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap">

<!-- Metodo 2: @font-face (fuentes propias) -->
<style>
  @font-face {
    font-family: 'MiFuente';
    src: url('/fonts/mifuente.woff2') format('woff2'),
         url('/fonts/mifuente.woff') format('woff');
    font-weight: 400 700;
    font-style: normal;
    font-display: swap; <!-- Muestra fallback hasta cargar -->
    unicode-range: U+0000-00FF; <!-- Solo carga los caracteres que necesitas -->
  }
</style>

Valores de font-display

ValorComportamientoUso recomendado
autoDecision del navegadorCuando no hay preferencia
swapMuestra fallback inmediatamente, cambia cuando cargaTexto importante (recomendado)
fallback Espera ~100ms, luego fallback, reintenta cortoFuentes secundarias
optionalEspera carga inicial, si no esta listo usa fallbackExperiencia optima de carga
blockOculta texto hasta que la fuente cargue (~3s)Solo branding/logo
Rendimiento de fuentes

Cada fuente extra agrega una peticion de red. Limita a 2-3 fuentes maximas. Usa font-display: swap para evitar el FOIT (Flash of Invisible Text) y preconnect para DNS prefetch.

Pointer Events y Touch

Maneja interacciones tactiles, mouse y stylus

Los Pointer Events son la API moderna que unifica mouse, tactil, stylus e incluso láser en una sola interfaz. Reemplazan a los Touch Events que solo funcionan en dispositivos móviles.

JavaScript
// Pointer Events: funciona con mouse, tactil y stylus
const elem = document.querySelector('#zona');

elem.addEventListener('pointerdown', (e) => {
  console.log('Tipo de input:', e.pointerType); // 'mouse', 'touch', 'pen'
  console.log('Posicion:', e.clientX, e.clientY);
  elem.setPointerCapture(e.pointerId); // Captura el pointer
});

elem.addEventListener('pointermove', (e) => {
  if (e.buttons === 0) return; // Solo procesar si hay boton presionado
  elem.style.transform = `translate(${e.offsetX}px, ${e.offsetY}px)`;
});

elem.addEventListener('pointerup', (e) => {
  elem.releasePointerCapture(e.pointerId);
});

// Eventos tactiles especificos (solo si necesitas gestos)
elem.addEventListener('touchstart', (e) => {
  e.preventDefault(); // Prevenir scroll mientras interactuas
  const touch = e.touches[0];
  console.log('Toque en:', touch.clientX, touch.clientY);
}, { passive: false });

Eventos de Pointer

EventoCuando se dispara
pointerdownBoton presionado sobre el elemento
pointerupBoton liberado
pointermoveMovimiento del puntero sobre el elemento
pointeroverPuntero entra en el elemento
pointeroutPuntero sale del elemento
pointerenterPuntero entra (no burbujea)
pointerleavePuntero sale (no burbujea)
pointercancelEl navegador cancela el tracking
Pointer Events vs Touch Events

Pointer Events es la API recomendada. Unifica mouse, tactil y stylus. Touch Events es antigua y solo funciona en pantallas tactiles. Usa { passive: true } para mejorar rendimiento si no necesitas preventDefault.
