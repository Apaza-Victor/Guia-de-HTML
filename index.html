Introduccion a HTML5

HTML (HyperText Markup Language) es el lenguaje de marcado estandar para crear paginas web. Define la estructura y el contenido de una pagina web mediante el uso de elementos (etiquetas) que representan diferentes tipos de contenido.

Que es HTML5?

HTML5 es la quinta revision importante del lenguaje HTML. Es la version mas reciente y estandar, que introduce nuevas funcionalidades, elementos semanticos y APIs que permiten crear aplicaciones web mas potentes y accesibles.

Caracteristicas principales

  • Elementos semanticos: Etiquetas que describen su significado (<header>, <nav>, <article>, <footer>)
  • Multimedia integrada: Soporte nativo para audio (<audio>) y video (<video>)
  • Canvas y SVG: Para graficos y animaciones
  • APIs del navegador: Geolocalizacion, Almacenamiento local, Drag & Drop, Web Workers, etc.
  • Formularios mejorados: Nuevos tipos de input y validacion
  • Soporte offline: Service Workers y Cache API
  • Mejoras en accesibilidad: ARIA roles y atributos
Por que aprender HTML?

HTML es la base de todo sitio web. Sin importar que framework o tecnologia uses, HTML siempre sera necesario para estructurar el contenido en la web.

Estructura Basica de HTML

Toda pagina HTML sigue una estructura basica que incluye una declaracion de tipo de documento, la raiz del documento, la seccion de encabezado y el cuerpo con el contenido visible.

HTML
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Mi primera pagina</title>
</head>
<body>
  <h1>Hola, mundo</h1>
  <p>Mi primera pagina web</p>
</body>
</html>

Explicacion de cada parte

HTML Semantico

HTML5 introdujo elementos semanticos que describen el significado del contenido que contienen, en lugar de solo definir su apariencia. Esto mejora la accesibilidad, el SEO y la mantenibilidad del codigo.

Etiquetas semanticas principales

<header>

Contenido introductorio o de navegacion.

<nav>

Enlaces de navegacion principales.

<main>

Contenido principal. Solo uno por pagina.

<article>

Contenido independiente y autocontenido.

<section>

Agrupa contenido tematico.

<aside>

Contenido complementario (sidebar).

<footer>

Pie de pagina.

<time>

Fecha o hora especifica.

<figure>/<figcaption>

Contenido ilustrativo con leyenda.

<details>/<summary>

Contenido colapsable.

Estructura semantica completa

HTML
<body>
  <header>
    <nav>
      <a href="/">Inicio</a>
      <a href="/blog">Blog</a>
      <a href="/contacto">Contacto</a>
    </nav>
  </header>
  <main>
    <article>
      <header>
        <h1>Titulo del articulo</h1>
        <time datetime="2024-01-15">15 de enero, 2024</time>
      </header>
      <section>
        <h2>Introduccion</h2>
        <p>Contenido del articulo...</p>
      </section>
      <figure>
        <img src="diagrama.png" alt="Diagrama">
        <figcaption>Diagrama de arquitectura</figcaption>
      </figure>
      <footer><p>Autor: Juan Perez</p></footer>
    </article>
    <aside>
      <h3>Articulos relacionados</h3>
      <ul><li><a href="#">Otro articulo</a></li></ul>
    </aside>
  </main>
  <footer><p>&copy; 2024 Mi Sitio</p></footer>
</body>
No abuses de las etiquetas semanticas

Cada etiqueta tiene un proposito especifico. Usa <section> para contenido tematico, no como sustituto de <div>.

SVG

SVG (Scalable Vector Graphics) permite crear graficos vectoriales directamente en HTML. A diferencia de Canvas, SVG es independiente de la resolucion y se puede manipular con CSS y JavaScript.

HTML
<svg width="200" height="200" viewBox="0 0 200 200">
  <circle cx="100" cy="100" r="80" fill="#6366f1"/>
  <rect x="20" y="150" width="160" height="30" rx="6" fill="#10b981"/>
  <text x="100" y="105" text-anchor="middle" fill="white">SVG</text>
</svg>

Progressive Web Apps (PWA)

Las PWA son aplicaciones web que funcionan como apps nativas: offline, instalables, con acceso a APIs del dispositivo.

Elementos esenciales de una PWA

  • manifest.json: Metadatos de la app (nombre, iconos, colores)
  • Service Worker: Script que intercepta peticiones y cachea recursos
  • HTTPS: Obligatorio para Service Workers
  • Iconos: Para la pantalla de inicio
manifest.json
{
  "name": "Mi Guia HTML5",
  "short_name": "GuiaHTML5",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#6366f1",
  "theme_color": "#6366f1",
  "icons": [
    { "src": "icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "icon-512.png", "sizes": "512x512", "type": "image/png" }
  ]
}
JavaScript (Service Worker)
// sw.js
const CACHE = 'guia-html5-v1';
const ASSETS = ['/', '/css/styles.css', '/js/app.js'];

self.addEventListener('install', (e) => {
  e.waitUntil(
    caches.open(CACHE).then(cache => cache.addAll(ASSETS))
  );
});

self.addEventListener('fetch', (e) => {
  e.respondWith(
    caches.match(e.request).then(r => r || fetch(e.request))
  );
});
