localStorage vs sessionStorage

CaracteristicalocalStoragesessionStorage

JavaScript
// Guardar datos
localStorage.setItem('nombre', 'Juan'); // Guarda un valor simple con su clave
localStorage.setItem('usuario', JSON.stringify({ id: 1 })); // Convierte objeto a JSON para guardarlo

// Leer datos
const nombre = localStorage.getItem('nombre'); // Obtiene el valor por su clave
const usuario = JSON.parse(localStorage.getItem('usuario')); // Convierte JSON de vuelta a objeto

// Eliminar y limpiar
localStorage.removeItem('nombre'); // Elimina una clave especifica
localStorage.clear(); // Borra todos los datos almacenados
Seguridad

Nunca almacenes información sensible como contrasenas en localStorage. Los datos son accesibles por cualquier script en la página.
