Selectores modernos

CSS
/* Hijo directo */
.padre > .hijo { color: red; } /* Selecciona hijos directos de .padre */

/* Hermano siguiente */
.a + .b { margin-left: 10px; } /* Selecciona .b solo si va justo despues de .a */

/* Attribute selectors */
a[href^="https"] { color: green; } /* Enlaces que inician con https */
input[type$="email"] { border: 2px solid blue; } /* Inputs cuyo tipo termina en email */

/* nth-child */
li:nth-child(odd) { background: #f0f0f0; } /* Alterna color en filas impares */

/* :not */
p:not(.excluido) { font-size: 16px; } /* Aplica estilos excepto a .excluido */

Flexbox

CSS
.container {
  display: flex; /* Activa Flexbox en el contenedor */
  justify-content: space-between; /* Distribuye items con espacio entre ellos */
  align-items: center; /* Centra items verticalmente */
  flex-wrap: wrap; /* Permite que los items salten de linea */
  gap: 16px; /* Espacio entre items */
}
.item {
  flex: 1 1 300px; /* Crece, encoge, ancho minimo de 300px */
}

CSS Grid

CSS
.grid {
  display: grid; /* Activa CSS Grid en el contenedor */
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr)); /* Columnas responsivas automaticas */
  gap: 20px; /* Espacio entre celdas del grid */
}
.grid-item:nth-child(1) {
  grid-column: span 2; /* El primer item ocupa 2 columnas */
}

Animaciones

CSS
@keyframes fadeInUp { /* Define la animacion fadeInUp */
  from { opacity: 0; transform: translateY(20px); } /* Estado inicial: invisible y abajo */
  to { opacity: 1; transform: translateY(0); } /* Estado final: visible y en posición */
}
.animate {
  animation: fadeInUp 0.5s ease forwards; /* Aplica la animacion de 0.5 segundos */
  transition: all 0.3s ease; /* Transicion suave para cambios de estado */
}

Custom Properties (Variables CSS)

CSS
:root { /* Define variables CSS globales */
  --color-primary: #6366f1; /* Color principal morado */
  --radius: 12px; /* Radio de borde redondeado */
  --shadow: 0 4px 6px rgba(0,0,0,0.1); /* Sombra suave */
}
.card {
  background: var(--color-primary); /* Usa la variable de color */
  border-radius: var(--radius); /* Usa la variable de radio */
  box-shadow: var(--shadow); /* Usa la variable de sombra */
}
