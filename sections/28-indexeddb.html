IndexedDB

Base de datos del navegador para almacenamiento pesado

IndexedDB es una base de datos completa en el navegador que permite almacenar grandes cantidades de datos estructurados, archivos y objetos. A diferencia de localStorage (5MB, strings), IndexedDB almacena objetos JavaScript y puede guardar megabytes o gigabytes de datos.

JavaScript
// Abrir o crear una base de datos
const request = indexedDB.open('MiBaseDatos', 1);

request.onupgradeneeded = (event) => {
  const db = event.target.result;
  // Crear un almacén de objetos (como una tabla)
  const store = db.createObjectStore('productos', { keyPath: 'id', autoIncrement: true });
  store.createIndex('nombre', 'nombre', { unique: false });
};

request.onsuccess = (event) => {
  const db = event.target.result;

  // Agregar datos
  const tx = db.transaction('productos', 'readwrite');
  const store = tx.objectStore('productos');
  store.add({ nombre: 'Laptop', precio: 999 });

  // Leer datos
  const getReq = store.get(1);
  getReq.onsuccess = () => console.log(getReq.result);
};
