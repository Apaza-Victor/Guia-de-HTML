Seguridad HTML

Protege tu sitio con atributos y meta tags de seguridad

HTML5 ofrece varios atributos y configuraciones para proteger tu sitio web contra ataques comunes como XSS (Cross-Site Scripting), clickjacking y inyección de código malicioso.

HTML
<!-- Content Security Policy (CSP) via meta tag -->
<meta http-equiv="Content-Security-Policy"
  content="default-src 'self'; script-src 'self' https://cdn.ejemplo.com; style-src 'self' 'unsafe-inline'; img-src 'self' data: https:;">

<!-- Iframe sandbox: restringe funcionalidades -->
<iframe src="externo.html"
  sandbox="allow-forms allow-scripts"
></iframe>
<!-- Sin sandbox: todo permitido | allow-scripts: permite JS | allow-same-origin: mantiene origen -->

<!-- Links externos seguros -->
<a href="https://ejemplo.com"
  target="_blank"
  rel="noopener noreferrer">Enlace externo</a>
<!-- noopener: impide que la pagina abierta acceda a window.opener -->
<!-- noreferrer: no envia informacion del referer -->

<!-- Subresource Integrity (SRI) -->
<script
  src="https://cdn.ejemplo.com/libreria.js"
  integrity="sha384-oqVuAfXRKap7fdgcCY5uykM6+R9GqQ8K/uxy9rx7HNQlGYl1kPzQho1wx4JwY8wC"
  crossorigin="anonymous"></script>
<!-- Verifica que el archivo no fue modificado en el CDN -->

<!-- Meta tag: prevenir sniffing de tipos -->
<meta http-equiv="X-Content-Type-Options" content="nosniff">

<!-- Prevenir framing (clickjacking) -->
<meta http-equiv="X-Frame-Options" content="DENY">

Vulnerabilidades y Protecciones

AmenazaProteccion HTMLDescripcion
XSSCSP + escape de contenidoEvita inyeccion de scripts maliciosos
ClickjackingX-Frame-OptionsImpide que tu sitio sea embebido en iframes maliciosos
Tabnabbingrel="noopener"Impide que links en target=_blank manipulen la pagina original
Tampering CDNSRI (integrity)Verifica que archivos externos no fueron modificados
MIME sniffingX-Content-Type-OptionsImpide que el navegador interprete archivos como otro tipo
Data leakagerel="noreferrer"No envia informacion del sitio de origen
Siempre escapes el contenido del usuario

Nunca insertes texto del usuario directamente en HTML con innerHTML. Usa textContent o librerias de escape como DOMPurify para prevenir ataques XSS.
