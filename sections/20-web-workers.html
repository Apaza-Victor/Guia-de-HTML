Web Workers y Fetch API

Fetch API

JavaScript
// GET basico
const response = await fetch('https://api.ejemplo.com/datos'); // Realiza peticion GET a la API
const data = await response.json(); // Convierte la respuesta a formato JSON

// POST con opciones
const res = await fetch('https://api.ejemplo.com/usuarios', { // Peticion POST con configuración
  method: 'POST', // Metodo HTTP para crear datos
  headers: { 'Content-Type': 'application/json' }, // Indica que envia JSON
  body: JSON.stringify({ nombre: 'Ana', email: 'ana@ej.com' }) // Datos a enviar como JSON
});

Web Workers

JavaScript
// worker.js
self.onmessage = (e) => { // Escucha mensajes del hilo principal
  self.postMessage(e.data * 2); // Devuelve el resultado multiplicado por 2
};

// Principal
const worker = new Worker('worker.js'); // Crea un hilo de ejecución en segundo plano
worker.postMessage(21); // Envía el valor 21 al worker
worker.onmessage = (e) => console.log(e.data); // Recibe y muestra el resultado (42)
