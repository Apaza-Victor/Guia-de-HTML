Web Fonts

Carga fuentes personalizadas de forma optimizada

Las fuentes web permiten usar tipografias personalizadas en tus paginas. HTML5 ofrece varias formas de cargarlas de forma optimizada para no afectar el rendimiento.

HTML
<!-- Metodo 1: Google Fonts con preload (recomendado) -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="preload" as="style"
  href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap">
<link rel="stylesheet"
  href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap">

<!-- Metodo 2: @font-face (fuentes propias) -->
<style>
  @font-face {
    font-family: 'MiFuente';
    src: url('/fonts/mifuente.woff2') format('woff2'),
         url('/fonts/mifuente.woff') format('woff');
    font-weight: 400 700;
    font-style: normal;
    font-display: swap; <!-- Muestra fallback hasta cargar -->
    unicode-range: U+0000-00FF; <!-- Solo carga los caracteres que necesitas -->
  }
</style>

Valores de font-display

ValorComportamientoUso recomendado
autoDecision del navegadorCuando no hay preferencia
swapMuestra fallback inmediatamente, cambia cuando cargaTexto importante (recomendado)
fallback Espera ~100ms, luego fallback, reintenta cortoFuentes secundarias
optionalEspera carga inicial, si no esta listo usa fallbackExperiencia optima de carga
blockOculta texto hasta que la fuente cargue (~3s)Solo branding/logo
Rendimiento de fuentes

Cada fuente extra agrega una peticion de red. Limita a 2-3 fuentes maximas. Usa font-display: swap para evitar el FOIT (Flash of Invisible Text) y preconnect para DNS prefetch.
