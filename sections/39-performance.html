Performance y Optimizacion

Resource Hints, Lazy Loading y buenas practicas

Optimizar el rendimiento de carga es fundamental para la experiencia del usuario y el SEO. HTML5 ofrece atributos y herramientas nativas para lograrlo.

HTML
<!-- Lazy Loading: carga diferida de imagenes e iframes -->
<img src="foto.jpg" alt="Descripcion" loading="lazy" decoding="async">
<iframe src="video.html" loading="lazy"></iframe>

<!-- fetchpriority: priorizar carga de recursos criticos -->
<img src="hero.jpg" fetchpriority="high" alt="Hero">
<img src="decoration.png" fetchpriority="low" alt="">

<!-- Resource Hints: adelantar conexiones y cargas -->
<!-- Preconnect: resuelve DNS + TCP + TLS anticipadamente -->
<link rel="preconnect" href="https://cdn.ejemplo.com">

<!-- DNS Prefetch: solo resuelve DNS -->
<link rel="dns-prefetch" href="https://fonts.googleapis.com">

<!-- Preload: carga critica que el navegador no puede descubrir solo -->
<link rel="preload" href="/fonts/inter.woff2" as="font" type="font/woff2" crossorigin>
<link rel="preload" href="/styles.css" as="style">

<!-- Prefetch: precarga para la proxima navegacion -->
<link rel="prefetch" href="/pagina-siguiente.html">

<!-- Module Preload: precarga modulos ES -->
<link rel="modulepreload" href="/js/modulo.js">

Resource Hints: Cuándo usar cada uno

HintCuando usarloEjemplo
preconnectSabes a que dominio iras (APIs, CDN)fonts.googleapis.com
dns-prefetchDominio secundario, menos urgenteAnalytics, tracking
preloadRecurso critico que el browser no descubre prontoFont principal, hero image
prefetchProbable que el usuario navegue ahiPagina siguiente
modulepreloadModulos ES que se importaran prontoApp modules
Metricas Core Web Vitals

LCP (<2.5s): Mayor elemento visible. FID (<100ms): Primera interaccion. CLS (<0.1): Estabilidad visual. Estas metricas determinan tu ranking en Google.
