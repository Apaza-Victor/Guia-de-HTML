HTML Living Standard

Que cambio desde HTML4 y que esta deprecado

HTML ya no se versiona como "HTML5". Desde 2019, el estandar se llama HTML Living Standard, mantenido por WHATWG. Esto significa que se actualiza continuamente con nuevas caracteristicas.

Etiquetas deprecadas (no usar)

EtiquetaQue haciaReemplazo moderno
<font>Cambiar color/tamaño de textoCSS con color, font-size
<center>Centrar contenidoCSS con text-align: center
<marquee>Texto desplazanteCSS animation / JS
<blink>Parpadeo de textoCSS animation
<frame>, <frameset>Frames multipagina<iframe>
<acronym>Abreviaturas<abbr>
<big>Texto grandeCSS font-size
<strike>Texto tachado<del> o CSS text-decoration
