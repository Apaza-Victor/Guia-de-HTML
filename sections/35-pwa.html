Progressive Web Apps (PWA)

Las PWA son aplicaciónes web que funcionan como apps nativas: offline, instalables, con acceso a APIs del dispositivo.

Elementos esenciales de una PWA

  • manifest.json: Metadatos de la app (nombre, iconos, colores)
  • Service Worker: Script que intercepta peticiones y cachea recursos
  • HTTPS: Obligatorio para Service Workers
  • Iconos: Para la pantalla de inicio
manifest.json
{
  "name": "Mi Guia HTML5", // Nombre completo de la aplicación
  "short_name": "GuiaHTML5", // Nombre corto para el icono de inicio
  "start_url": "/", // URL que se abre al iniciar la PWA
  "display": "standalone", // Se ejecuta como app nativa sin barra del navegador
  "background_color": "#6366f1", // Color de fondo al cargar la app
  "theme_color": "#6366f1", // Color de la barra de estado en moviles
  "icons": [ // Iconos para diferentes tamanos de pantalla
    { "src": "icon-192.png", "sizes": "192x192", "type": "image/png" }, // Icono para moviles
    { "src": "icon-512.png", "sizes": "512x512", "type": "image/png" } // Icono para pantallas grandes
  ]
}
JavaScript (Service Worker)
// sw.js
const CACHE = 'guia-html5-v1'; // Nombre de la cache para almacenar recursos
const ASSETS = ['/', '/css/styles.css', '/js/app.js']; // Recursos a cachear

self.addEventListener('install', (e) => { // Se ejecuta al instalar el service worker
  e.waitUntil( // Espera a que termine la cache antes de continuar
    caches.open(CACHE).then(cache => cache.addAll(ASSETS)) // Abre la cache y guarda todos los assets
  );
});

self.addEventListener('fetch', (e) => { // Intercepta cada peticion de red
  e.respondWith( // Responde con el resultado de la cache o la red
    caches.match(e.request).then(r => r || fetch(e.request)) // Si esta en cache la usa, si no fetch
  );
});
