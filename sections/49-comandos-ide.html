Consejos para Codificar Mas Rapido

Domina Emmet

Emmet es la herramienta mas poderosa para HTML. Escribe abreviaturas y presiona Tab:

Ejemplos Emmet 
! + Tab                → Plantilla HTML5 completa
div#app>ul>li*3>a + Tab  → Estructura anidada con 3 enlaces
style + Tab             → Etiqueta style vacia
link:css + Tab          → Link a CSS

Aprende la Paleta de Comandos

Presiona Ctrl + Shift + P y escribe lo que necesitas. Es mas rapido que buscar en menus. Ejemplos:

  • Format Document - Formatea todo el archivo
  • Toggle Word Wrap - Activa/desactiva ajuste de linea
  • Theme - Cambia el tema del editor
  • Snippets - Administra fragmentos de codigo reutilizables

Usa Snippets Personalizados

Crea fragmentos de codigo reutilizables en VS Code:

  1. Presiona Ctrl + Shift + P → Configure User Snippets
  2. Selecciona html.json
  3. Agrega tu snippet:
JSON 
{
  "Section HTML5": {
    "prefix": "sec",
    "body": [
      '<section class="section" id="$1">',
      '  <div class="section__header">',
      '    <span class="section__number">Seccion</span>',
      '    <h2 class="section__title">$2</h2>',
      '  </div>',
      '  $0',
      '</section>'
    ],
    "description": "Crear seccion HTML5"
  }
}

Ahora escribe sec + Tab y se genera la estructura completa.
