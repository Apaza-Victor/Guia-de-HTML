History API

Gestiona el historial de navegacion sin recargar

La History API permite manipular la barra de direcciones del navegador sin recargar la pagina, fundamental para Single Page Applications (SPAs).

JavaScript
// Agregar una nueva entrada al historial
history.pushState(
  { page: 2 },         // state: datos asociados a la entrada
  'Pagina 2',           // title: titulo de la entrada (no usado por todos)
  '/pagina-2'           // url: nueva URL en la barra de direcciones
);

// Reemplazar la entrada actual (no agrega nueva)
history.replaceState(
  { page: 1 },
  'Pagina 1',
  '/pagina-1'
);

// Navegar con los botones atras/adelante
window.addEventListener('popstate', (event) => {
  if (event.state) {
    console.log('Navegando a:', event.state.page);
    cargarPagina(event.state.page);
  }
});

// Ejemplo practico: Router simple
function navegarA(url, datos) {
  history.pushState(datos, '', url);
  renderizarContenido(url);
}

// Manejar recarga de pagina
window.addEventListener('popstate', (e) => {
  const url = location.pathname;
  renderizarContenido(url);
});
pushState vs replaceState

pushState agrega una nueva entrada (el boton Atras funciona). replaceState reemplaza la actual (el boton Atras va a la anterior). El evento popstate se dispara al navegar con Atras/Adelante.
