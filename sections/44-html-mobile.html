HTML en Moviles

Meta tags, manifest y optimizaciones para dispositivos moviles

Desarrollar para moviles requiere meta tags especificos, configuracion del manifest de la PWA y optimizaciones de rendimiento para conexiones lentas y pantallas pequeñas.

HTML
<!-- Meta tags esenciales para movil -->
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=5.0">
<meta name="theme-color" content="#6366f1" media="(prefers-color-scheme: light)">
<meta name="theme-color" content="#1e1b4b" media="(prefers-color-scheme: dark)">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
<meta name="mobile-web-app-capable" content="yes">

<!-- Touch icons para iOS -->
<link rel="apple-touch-icon" href="/icon-180.png">

<!-- Manifest PWA -->
<link rel="manifest" href="/manifest.json">

<!-- Prevenir llamadas telefonicas accidentales -->
<a href="tel:+59112345678">Llamar</a>

<!-- Prevenir zoom en inputs (iOS) -->
<input type="text" inputmode="numeric" style="font-size:16px">
<!-- font-size >= 16px previene autozoom en iOS -->
