Pointer Events y Touch

Maneja interacciones tactiles, mouse y stylus

Los Pointer Events son la API moderna que unifica mouse, tactil, stylus e incluso láser en una sola interfaz. Reemplazan a los Touch Events que solo funcionan en dispositivos móviles.

JavaScript
// Pointer Events: funciona con mouse, tactil y stylus
const elem = document.querySelector('#zona');

elem.addEventListener('pointerdown', (e) => {
  console.log('Tipo de input:', e.pointerType); // 'mouse', 'touch', 'pen'
  console.log('Posicion:', e.clientX, e.clientY);
  elem.setPointerCapture(e.pointerId); // Captura el pointer
});

elem.addEventListener('pointermove', (e) => {
  if (e.buttons === 0) return; // Solo procesar si hay boton presionado
  elem.style.transform = `translate(${e.offsetX}px, ${e.offsetY}px)`;
});

elem.addEventListener('pointerup', (e) => {
  elem.releasePointerCapture(e.pointerId);
});

// Eventos tactiles especificos (solo si necesitas gestos)
elem.addEventListener('touchstart', (e) => {
  e.preventDefault(); // Prevenir scroll mientras interactuas
  const touch = e.touches[0];
  console.log('Toque en:', touch.clientX, touch.clientY);
}, { passive: false });

Eventos de Pointer

EventoCuando se dispara
pointerdownBoton presionado sobre el elemento
pointerupBoton liberado
pointermoveMovimiento del puntero sobre el elemento
pointeroverPuntero entra en el elemento
pointeroutPuntero sale del elemento
pointerenterPuntero entra (no burbujea)
pointerleavePuntero sale (no burbujea)
pointercancelEl navegador cancela el tracking
Pointer Events vs Touch Events

Pointer Events es la API recomendada. Unifica mouse, tactil y stylus. Touch Events es antigua y solo funciona en pantallas tactiles. Usa { passive: true } para mejorar rendimiento si no necesitas preventDefault.
