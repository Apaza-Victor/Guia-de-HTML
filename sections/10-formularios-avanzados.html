Validación nativa, FormData y Constraint Validation API

Más allá de los tipos de input básicos, HTML5 ofrece una API completa de validación nativa que elimina la necesidad de librerías externas para muchos casos comunes.

HTML + JS
<!-- Constraint Validation API -->
<form id="miFormulario">
  <input type="email" required minlength="5" pattern="[a-z]+@[a-z]+\.[a-z]{2,}">
  <input type="text" required maxlength="50">
  <button type="submit">Enviar</button>
</form>

<!-- JavaScript: Validacion personalizada -->
const form = document.querySelector('#miFormulario');
const email = form.querySelector('input[type="email"]');

// Validar al enviar
form.addEventListener('submit', (e) => {
  e.preventDefault();
  if (!form.checkValidity()) {
    // Muestra los mensajes de error nativos del navegador
    form.reportValidity();
    return;
  }
  // Crear FormData automaticamente desde el formulario
  const datos = new FormData(form);
  for (const [clave, valor] of datos) {
    console.log(`${clave}: ${valor}`);
  }
});

// Personalizar mensaje de error
email.addEventListener('input', () => {
  if (email.validity.typeMismatch) {
    email.setCustomValidity('Ingresa un email valido (ejemplo@dominio.com)');
  } else {
    email.setCustomValidity(''); // Limpiar error personalizado
  }
});

Propiedades de Constraint Validation

PropiedadDescripcionRetorna
validity.validTrue si el campo cumple todas las validacionesBoolean
validity.valueMissingCampo requerido vacíoBoolean
validity.typeMismatchEl tipo no coincide (email, url, number)Boolean
validity.patternMismatchEl valor no coincide con el patternBoolean
validity.tooShortMínimo de caracteres no alcanzadoBoolean
validity.tooLongMáximo de caracteres excedidoBoolean
validity.rangeUnderflowValor menor que el mínimoBoolean
validity.rangeOverflowValor mayor que el máximoBoolean
checkValidity()Valida y muestra errores nativos si fallaBoolean
reportValidity()Valida y muestra popup de error al usuarioBoolean
setCustomValidity(msg)Establece un mensaje de error personalizadovoid
