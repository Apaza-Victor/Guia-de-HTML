Resize y Performance Observer

Observa cambios de tamaño y metricas de rendimiento

El ResizeObserver detecta cambios en el tamaño de elementos, y el PerformanceObserver monitorea metricas de rendimiento de la pagina como tiempos de carga y interacciones.

JavaScript
// ResizeObserver: detectar cambios de tamaño
const resizeObserver = new ResizeObserver((entries) => {
  for (const entry of entries) {
    const { width, height } = entry.contentRect;
    console.log(`Tamaño: ${width}x${height}px`);
  }
});
resizeObserver.observe(document.querySelector('.mi-elemento'));

// PerformanceObserver: monitorear metricas de carga
const perfObserver = new PerformanceObserver((list) => {
  for (const entry of list.getEntries()) {
    console.log(`${entry.name}: ${entry.startTime.toFixed(0)}ms`);
  }
});
perfObserver.observe({ entryTypes: ['largest-contentful-paint', 'first-input'] });
